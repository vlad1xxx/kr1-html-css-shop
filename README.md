# Учебный интернет-магазин (kr1-html-css-shop)

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт учебного интернет-магазина:
семантическая разметка, единая навигация, якорные ссылки, карточки товаров,
таблица характеристик, форма заявки, модальное окно, CSS-переменные,
состояния интерфейса, Flexbox, CSS Grid, базовое БЭМ-именование и
позиционирование элементов.

## Описание проекта

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».
Сайт разработан без CSS-фреймворков и без полноценной JavaScript-интерактивности:
JavaScript используется только для открытия/закрытия модального окна и базовой
валидации формы заявки.

## Обязательные страницы

| Страница | Содержание |
| --- | --- |
| `index.html` | главная страница: hero-блок, преимущества, сетка популярных товаров |
| `catalog.html` | каталог: сетка карточек товаров, статический блок фильтров (sticky) |
| `product.html` | карточка товара: изображение, описание, таблица характеристик, цена, кнопка заявки |
| `order.html` | отдельная страница формы оформления заявки |
| `contacts.html` | контактная информация и ссылка на форму заявки |

Каждая страница подключает общий `css/style.css`, использует единую навигацию
(`header`, `nav`) и семантическую разметку (`main`, `section`, `article`, `aside`, `footer`),
имеет уникальный `title` и `meta description`.

## Реализованные обязательные элементы

- семантическая HTML-разметка: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`;
- единая навигация между страницами и якорные ссылки (`index.html#advantages`, `index.html#popular`);
- хлебные крошки на внутренних страницах;
- карточки товаров с бейджами («Хит», «Скидка») и БЭМ-именованием классов;
- таблица характеристик товара (`caption`, `thead`, `tbody`, `th`, `td`) на `product.html`;
- форма заявки с валидацией: `order.html` и модальное окно (`<dialog>`) на главной странице;
- CSS-переменные в `:root`, состояния `:hover`, `:focus-visible`, `:disabled`;
- Flexbox (навигация, карточка товара) и CSS Grid (сетка карточек, раскладка каталога, страница товара);
- базовое БЭМ-именование: `site-header__*`, `site-nav__*`, `product-card__*`, `order-form__*`;
- позиционирование: `position: relative` (карточка товара), `position: absolute` (бейдж),
  `position: sticky` (боковой фильтр каталога), `position: fixed` (кнопка «Оставить заявку»),
  `z-index` (бейдж, фильтр, фиксированная кнопка).

## Самостоятельные доработки

- два сценария оформления заявки: быстрая форма в модальном окне на карточке товара
  и отдельная страница `order.html`;
- отдельная страница карточки товара `product.html` с изображением-заглушкой и таблицей характеристик;
- бейджи товаров («Хит», «Скидка») через модификатор `product-card--sale` и позиционирование `absolute`;
- sticky-блок фильтров на странице каталога;
- фиксированная кнопка «Оставить заявку» на всех страницах, кроме самой формы;
- подсветка активного пункта меню модификатором `site-nav__link--active`;
- подсветка цели якорной ссылки через `:target` и плавная прокрутка `scroll-behavior: smooth`;
- переиспользуемый компонент `order-form` (единые БЭМ-классы для формы в диалоге и на отдельной странице).
